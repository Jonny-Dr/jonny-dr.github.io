神经网络反向传播详解（流程串联）

发布日期：2026-08-08
深度学习 神经网络 Python PyTorch

深度学习完整流程

整体流程：数据处理 → 创建模型 → 模型训练 → 模型测试 → 部署模型

1 数据处理

不同类型数据处理方式不同：csv、excel、图片、语音、文本/token等。下面以csv表格数据为例。

1.1 CSV数据处理步骤

  1. 读取源文件，分离特征数据与目标标签数据

    • 特征数据：模型输入x
    • 目标数据（标签）：模型输出y
    • 特征与标签可以放在同一个文件，也可以拆分到不同文件，根据业务需求选择。

  2. 检查数据集类别分布是否均衡

# 统计各个标签样本数量，判断数据是否倾斜
print(y.value_counts())
  1. 数据集划分：训练集 / 测试集
  • 常规划分比例：80%训练集，20%测试集
  • ⚠️ 当数据分布不均衡时，开启stratify=y保证划分后训练、测试集类别分布和原数据集保持一致。
from sklearn.model_selection import train_test_split

x_train, x_test, y_train, y_test = train_test_split(
    x, y,
    test_size=0.2,
    random_state=42,
    stratify=y   # 数据不均衡必须加上该参数
)
  1. 数据标准化（StandardScaler）
  • 作用：将原始数据转换为均值为0，方差为1的标准正态分布，加速模型收敛。
  • ✅ 训练集：fit_transform()，先学习训练集统计特征，再做转换
  • ✅ 测试集：只做transform()，禁止fit，复用训练集得到的均值方差，防止数据泄露。
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
x_train = scaler.fit_transform(x_train)
x_test = scaler.transform(x_test)
  1. 获取业务维度信息
    获取特征数量、输出目标类别数量，为后续搭建神经网络层提供参数。

1.2 其他类型数据简单说明

  • 图片：读取图片、resize尺寸、归一化像素、数据增强、转为张量
  • 文本：分词、token编码、padding补齐序列长度
  • 语音：音频读取、提取梅尔频谱等特征，转为张量

    test_dataset = TensorDataset(torch.tensor(x_test, dtype=torch.float32),
                                 torch.tensor(y_test.values, dtype=torch.int64))

    # 4- 特征个数获取

    # 4- 目标个数获取
    targets = len(np.unique(y_train))

    # 5- 返回数据集
    return train_dataset,test_dataset,features,targets

2 创建模型（PyTorch自定义网络）

基于torch.nn.Module自定义神经网络

  1. 类继承父类 nn.Module
  2. 必须调用父类构造函数 super().__init__()
  3. 在构造函数内部定义网络各层（全连接层、Dropout层等）
  4. 实现forward()前向传播函数：定义数据流动逻辑，包含加权求和、非线性激活函数、dropout、输出层激活（softmax）

关键要点

  • 激活函数：根据任务选择，如ReLU、Sigmoid、Tanh
  • Dropout：神经元失活，例如dropout(0.2)，随机让20%神经元失效，抑制过拟合，避免模型过度依赖少数神经元
  • Softmax：多用于多分类任务输出层，输出各个类别概率
import torch.nn as nn

class PhoneAnnModel(nn.Module):
    def __init__(self,features,targets):
        # 初始化父类
        super().__init__()

        # 搭建网络结构
        # 4层（输入层，隐藏层*2，输出层）
        self.linear = nn.Linear(features,128)
        self.linear2 = nn.Linear(128,256)
        self.linear3 = nn.Linear(256,128)
        self.output = nn.Linear(128,targets)

    # 前向传播
    # 隐藏层使用relu函数，中间增加dropout损失因子，随机20%神经元失活，避免过拟合
    # 后续会使用交叉熵损失函数，所以输出层不需要应用激活函数
    def forward(self,x):
        x = torch.relu(self.linear(x))
        x = torch.dropout(x,0.2,self.training)
        x = torch.relu(self.linear2(x))
        x = torch.dropout(x,0.2,self.training)
        x = torch.relu(self.linear3(x))
        x = torch.dropout(x,0.2,self.training)
        x = self.output(x)

        return x

3 模型训练完整流程

  1. 设备判断：优先使用GPU加速
    • 判断cuda是否可用，将模型、数据移动到GPU设备。
  2. 数据集封装为DataLoader
    • 分批次加载数据，避免一次性全部加载进内存造成内存溢出。
  3. 设置随机种子
    • 固定随机因子，保证实验可复现。
  4. 实例化自定义模型对象
  5. 选择损失函数
    • 根据任务类型选择：分类任务、回归任务损失函数不一样。
  6. 选择优化器
    • 常用Adam优化器：自适应学习率，集成动量机制，训练过程更稳定。
  7. (可选)手动调整学习率
    • 学习率调度器，在训练循环中动态更新学习率。
  8. 循环迭代训练（epoch循环）
    1. 将模型、数据移动到GPU设备
    2. 设置模型为训练模式 model.train()
    3. 输入数据执行前向传播，得到预测结果
    4. 损失函数计算预测值与真实标签之间损失
    5. 梯度清零 → 反向传播求梯度 → 优化器更新网络参数
  9. 训练完成保存模型权重

训练循环核心代码样例

def train_model(train_dataset,features,targets):
    # 判断设备是否支持显卡运行，以便将模型放到显卡上
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

    # 数据封装：TensorDataset->DataLoader，为了防止内存溢出
    dataloader = DataLoader(train_dataset,batch_size=8,shuffle=True)

    # 设置随机因子，为了每次的数据固定
    torch.manual_seed(815)

    # 创建模型实例对象
    model = PhoneAnnModel(features,targets).to(device)

    # 创建损失函数
    criterion = nn.CrossEntropyLoss()

    # 创建优化器(Adam，优化学习率以及梯度更新)
    optimizer = torch.optim.Adam(model.parameters(),lr=0.001)

    # 模型训练
    # 创建学习率调整器
    scheduler = torch.optim.lr_scheduler.StepLR(optimizer,step_size=10,gamma=0.1)

    # 定义模型训练轮次
    num_epochs = 100

    # 模型开始训练
    for epoch in range(num_epochs):
        # 批次总损失值
        total_loss = 0.0
        # 批次样本数
        total_sample_num = 0

        for x_train_tmp,y_train_tmp in dataloader:
           # 将数据放到显卡上
           x_train_tmp = x_train_tmp.to(device)
           y_train_tmp = y_train_tmp.to(device)

           # 设置模型为训练模式
           model.train()

           # 模型开始训练
           # 数据预测。也是前向传播
           y_pred = model(x_train_tmp)

           # 计算损失值，使用前面创建的交叉熵损失函数
           loss = criterion(y_pred,y_train_tmp)

           # 批次累计损失值
           total_loss += loss.item() * len(x_train_tmp)
           total_sample_num += len(x_train_tmp)

           # 梯度清零、反向传播、参数更新
           optimizer.zero_grad()
           loss.backward()
           optimizer.step()

        # 学习率可以在此处手动调整
        scheduler.step()

        # 计算每轮次总的平均损失值
        total_avg_loss = total_loss/total_sample_num
        print(f"第{epoch+1}轮次，总的平均交叉熵损失值{total_avg_loss}")

    # 保存训练好的模型
    torch.save(model.state_dict(),"model/phone_ann.pt")

4 模型测试流程

测试阶段不更新权重，只做推理评估模型效果

  1. 重新创建模型实例对象
  2. 加载训练保存好的模型权重
  3. 测试数据集封装为DataLoader，分批读取，防止内存溢出
  4. 循环遍历测试集做推理
    1. 设置模型为测试模式 model.eval()
    2. 开启torch.no_grad()关闭梯度计算，节省显存
    3. 执行前向传播推理
    4. 收集预测结果，计算准确率、损失等评估指标

测试代码样例

def predict_model(test_dataset,features,targets):
    # 加载训练好的模型
    model = PhoneAnnModel(features,targets)
    model.load_state_dict(torch.load("model/phone_ann.pt"))

    # 将数据封装为DataLoader，为了防止内存溢出,此处不需要打乱数据集
    dataloader = DataLoader(test_dataset,batch_size=3,shuffle=False)

    # 进行预测
    correct_count = 0 # 预测正确的样本条数

    for x_test_tmp,y_test_tmp in dataloader:
        # 模式设置
        model.eval()

        #预测数据
        y_pred = model(x_test_tmp)

        # 预测结果
        y_pred_target = torch.argmax(y_pred,dim=1)
        correct_count =  correct_count + (y_pred_target==y_test_tmp).sum()

    # 最终的准确率
    accuracy = correct_count / len(test_dataset)
    print("预测准确率：",accuracy)

6 常见踩坑总结

  1. 标准化：测试集不能fit，只能transform，防止数据泄露
  2. 数据不均衡：划分数据集要加stratify分层采样
  3. 模式切换：训练model.train()；测试model.eval()，两者不能搞混
  4. 测试阶段务必加上torch.no_grad()，不计算梯度，节约显存
  5. Dropout只在训练阶段生效，eval模式自动关闭dropout
  6. 模型、tensor数据必须放到同一个设备（CPU / GPU），否则会报错
