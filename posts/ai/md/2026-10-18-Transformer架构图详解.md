# Transformer 架构详解

> 本文档基于 **Transformer 整体架构流程** 与 **位置编码机制** 两大部分，采用"作用 + 白话解释"的方式帮助理解核心原理。

---

## 一、总体总结流程

Transformer 的完整处理链路如下：

```
输入文字 -> 嵌入(Embedding) -> 位置编码(Positional Encoding)
  -> 编码器多层加工(注意力 + 前馈)
  -> 解码器多层加工(掩码注意力 + 关联编码器 + 前馈)
  -> 线性层(Linear) -> Softmax -> 输出概率选词
```

**一句话概括**：把文字变成向量，加上位置信息，经过编码器理解语义、解码器逐词生成，最后输出概率最高的词。

---

## 二、Transformer 整体架构

Transformer 由 **四个部分** 组成：输入部分、编码器部分、解码器部分、输出部分。

```
                Output（输出部分）
                   │
              Probabilities（概率）
                   │
                Softmax（激活层）
                   │
                 Linear（线性层）
                   │
        ┌───────────────────────┐
        │      解码器部分         │
        │   Add & Norm          │
        │   Feed Forward        │
        │   Add & Norm          │
        │   Multi-Head Attention│  ← 关联编码器输出
        │   Add & Norm          │
        │   Masked Multi-Head   │  ← 掩码多头注意力
        │       Attention       │
        └───────────────────────┘
        ┌───────────────────────┐
        │      编码器部分         │   Nx（重复堆叠，论文为6次）
        │   Add & Norm          │
        │   Feed Forward        │
        │   Add & Norm          │
        │   Multi-Head Attention│
        └───────────────────────┘
        ┌───────────────────────┐
        │   Positional Encoding │
        │   Input Embedding     │
        │   Inputs（输入部分）    │
        └───────────────────────┘
```

### 🎯 整个架构的核心
> **注意力机制抓关联，多层堆叠挖深度，残差归一化稳训练。**

## 三、各组件详细说明（作用 + 白话）

### 1. Input Embedding —— 源文本嵌入层
- **作用**：把输入的文字（例如 1 个单词）转成数值向量（词向量）。
- **白话**：计算机看不懂文字，把文字转成能看懂的向量。例如 `"你好" -> [0.1, -0.3 ...]`。

### 2. Positional Encoding —— 位置编码
- **作用**：给词向量加"位置信息"。
- **白话**：Transformer 本身不明白词的顺序，例如"我打你"和"你打我"顺序不同含义就不同，所以得额外给每个位置贴"坐标标签"，告诉模型谁前谁后。

### 3. Multi-Head Attention —— 多头注意力
- **作用**：让模型**同时从多个角度关注句子里的词**。
- **白话**：以"猫追老鼠"为例，既要关注"猫"和"追"的关系，也要关注"猫"和"老鼠"的关系，还能对比"猫"和"老鼠"之间的关联。

### 4. Add & Norm —— 残差连接 + 层归一化
- **作用**：让训练更稳、更高效。
- **白话**：
  - **Add（残差连接）**：把注意力层的输入和输出加在一起，防止信息丢太多。
  - **Norm（层归一化）**：把数据归一化（数值限制在某个范围内），避免训练时跑偏，防止梯度消失 / 梯度爆炸。

### 5. Feed Forward —— 前馈网络
- **作用**：对每个位置的词向量**单独强化特征**。
- **白话**：经过注意力层后，再用全连接网络加工一下，给每个词"注入更多细节"。例如：强化"猫"的动物属性、"追"的动作属性。

### 6. Nx —— 重复堆叠
- **作用**：把上面的"多头注意力 + Add&Norm + 前馈网络"重复 N 次（论文里是 6 次）。
- **白话**：一层不够深，多堆几层，让模型"层层递进"理解文本，从表面语义 → 深层逻辑。

### 7. Masked Multi-Head Attention —— 掩码多头注意力（解码器）
- **作用**：防止**"偷看未来的词"**。
- **白话**：解码器是一步步生成输出的，只能用"已生成的词"，不能用未生成的词。

### 8. 解码器中的 Multi-Head Attention —— 关联编码器
- **作用**：让解码器**关注编码器输出的内容**。
- **白话**：例如翻译时，解码器要生成法语词，得盯着处理后的英文词义，确保翻译准确，找对应关系。

### 9. Output Embedding —— 目标文本嵌入层
- **作用**：和源文本嵌入层类似，把输出的目标文字转成向量。
- **白话**（英译法案例）：把法语单词转成数值向量，方便解码器处理。

### 10. Linear —— 线性层
- **作用**：把解码器输出的向量，调整成 **vocab_size（词汇表大小）** 维度。
- **白话**：例如词汇表有 1 万个词，就把向量变成 1 万维，每个维度对应 1 个词的概率分数。

### 11. Softmax —— 激活层
- **作用**：把线性层输出的数值，转成**概率**，概率总和为 1，模型就知道该选哪个词输出。

## 四、位置编码公式介绍

Transformer 中直接采用 **正弦函数（sin）和余弦函数（cos）** 来编码位置信息。

### 4.1 公式

**偶数维度（2i）：**
```
                     pos
PE(pos, 2i) = sin( ───────────── )
                   2i
                  ────
                 d_model
                10000
```

**奇数维度（2i+1）：**
```
                       pos
PE(pos, 2i+1) = cos( ───────────── )
                     2i
                    ────
                   d_model
                  10000
```

### 4.2 参数解释

| 参数 | 含义 | 示例 |
|------|------|------|
| `pos` | 词在句子里的位置（从 0 或 1 开始数） | `"我爱吃西瓜"`，`爱` 的 pos 从 0 数是 1 |
| `i` | 维度的索引 | 512 维的词向量，i 就是 0 到 255（因为 2i 要覆盖 0-511 维） |
| `d_model` | 词向量的维度 | 例如 512 |
| `10000^(2i/d_model)` | 周期缩放因子 | 不同的 i 会让周期不一样：**i 越大，周期越长** |

### 4.3 三角函数的应用优势（重点）

三角函数应用在位置编码中的一个重要优点：**对于任意的 PE(pos+k)，都可以表示为 PE(pos) 的线性函数**，大大方便计算。

使用到的和角公式：
```
sin(α + β) = sin(α)cos(β) + cos(α)sin(β)
cos(α + β) = cos(α)cos(β) - sin(α)sin(β)
```

并且，**周期性函数不受序列长度的限制**，可以增强模型的泛化能力。

## 五、位置编码计算示例（逐步推导）

### 假设条件
- 句子位置：`pos = 2`（即第 2 个词）
- 词向量维度：`d_model = 4`（这里简化处理，实际开发常用 512）
- 因为 `2i` 要小于 4，即 `i < 2`，所以 **i 可以取 0、1**

### Step 1：当 i = 0 时

**偶数维度**（PE(2,0)）：

```
                        2
PE(2,0) = sin( ──────────────── ) = sin(2) = 0.909
                       0/4
                  10000
```
- `2i/d_model = 0/4 = 0`
- `10000^0 = 1`
- 即 `sin(2/1) = sin(2) ≈ 0.909`

**奇数维度**（PE(2,1)）：
```
                        2
PE(2,1) = cos( ──────────────── ) = cos(2) ≈ -0.416
                       0/4
                  10000
```
- 即 `cos(2/1) = cos(2) ≈ -0.416`

### Step 2：当 i = 1 时

**偶数维度**（PE(2,2)）：
```
                         2
PE(2,2) = sin( ────────────────── ) = sin(2/100) = sin(0.02) ≈ 0.020
                      2/4 = 1/2
                  10000
```
- `2i/d_model = 2/4 = 1/2`
- `10000^(1/2) = 100`
- 即 `sin(2/100) = sin(0.02) ≈ 0.020`

**奇数维度**（PE(2,3)）：
```
                         2
PE(2,3) = cos( ────────────────── ) = cos(2/100) = cos(0.02) ≈ 0.998
                      2/4 = 1/2
                  10000
```
- 即 `cos(2/100) = cos(0.02) ≈ 0.998`

### 最终位置编码向量
```
PE(2) = [ 0.909   -0.416   0.020   0.998 ]
        └────┘   └─────┘   └────┘  └────┘
         PE(2,0) PE(2,1)  PE(2,2) PE(2,3)
```

## 六、位置编码的好处

### 6.1 直观理解
- **计算更快**：尤其是句子很长时，不用每个位置都重新算三角函数。
- **可以推导**：靠"位置 pos"的编码可以推导出来，看似复杂，其实简单。
  - 例如：`pos(5) -> pos(2 + 3)`

### 6.2 好处总结

1. **记住词的顺序**：通过周期性函数，给每个位置贴独特的标签，让模型区分"我爱你"和"你爱我"。
2. **计算高效**：靠线性组合推导新位置编码，不用重复计算三角函数，省算力。
3. **适应任意长度**：不管句子多长，随时能算编码，泛化能力强。
4. **模型处理语言时更聪明、更灵活**。

## 七、核心要点速记（复习）

| 要点 | 核心内容 |
|------|---------|
| 架构流程 | 嵌入 → 位置编码 → 编码器（注意力+前馈）→ 解码器（掩码注意力+关联编码器+前馈）→ 线性 → Softmax → 选词 |
| 注意力 | 多头注意力从多个角度抓词与词之间的关联 |
| 掩码注意力 | 解码器逐词生成，只能看已生成的词，不能偷看未来 |
| 残差 + 归一化 | 防止信息丢失、梯度消失/爆炸，让训练更稳 |
| 前馈网络 | 对每个词单独强化特征 |
| Nx 堆叠 | 多层叠加，从表面语义理解到深层逻辑（论文用 6 层） |
| 位置编码 | 用 sin/cos 给每个位置贴坐标标签，让模型懂语序 |
| 位置编码三大优点 | 记住顺序、计算高效、适应任意长度 |
| 整个架构核心 | 注意力机制抓关联，多层堆叠挖深度，残差归一化稳训练 |
