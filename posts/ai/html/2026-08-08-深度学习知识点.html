神经网络反向传播详解（知识点整合）

发布日期：2026-08-08
深度学习 神经网络 Python PyTorch

深度学习

前置解惑——导数 / 梯度

1. 模型训练的本质：改错

神经网络一开始权重是随机的，预测全是错的。我们需要：一点点修改权重，让错误越来越小。

2. 问题来了：权重到底该调大还是调小？调多少？

这里就需要 梯度（多元导数）

梯度 = 损失对权重的敏感程度 + 误差下降方向

  • 梯度为正：权重 调小，损失会下降

  • 梯度为负：权重 调大，损失会下降

  • 梯度绝对值越大：当前权重误差越大，需要改得多

  • 梯度接近0：模型快收敛、误差很小了

终极一句话懂梯度：

梯度就是告诉模型：每个权重往哪边改、改多大，能让错误变小。

没有梯度，模型完全不知道怎么更新参数，训练彻底不成立。

完整串行

知识串联总结（张量→梯度→自动微分→损失函数→梯度下降→CNN→RNN）

1、张量运算：深度学习的底层载体（地基）

张量就是多维数组，是PyTorch唯一计算单元：

  • 标量=0维、向量=1维、矩阵=2维、图像/批次数据=3-4维张量

  • 张量运算：加减乘除、矩阵乘法、切片、维度变换等

  • 神经网络所有前向、反向计算，本质全是张量运算

  • GPU（MPS/CUDA）就是用来加速大批量张量并行计算

一句话：所有数据、权重、计算结果，全部必须是张量。

2、导数/梯度：模型优化的数学指南针

导数代表函数在某一点的变化速率。
在深度学习里我们叫梯度（多元函数的导数）：

  • 目标：算出损失函数对每一个权重参数的梯度，看权重往哪个方向调整，能让损失变小。

  • 梯度方向 = 损失上升最快的方向

  • 训练要做反向操作：逆着梯度走，损失就会不断下降

  • 手动求导极其繁琐，所以引出了自动微分

一句话：梯度给模型指明“改错方向”，是训练的核心依据。

3、自动微分（Autograd）：自动算梯度的工具

自动微分 = 不用手写求导公式，框架自动计算导数。

  1. 给张量开启 requires_grad=True，标记它为可求导参数（权重）
  2. 前向传播：执行一遍张量运算，算出预测结果和损失值
  3. loss.backward()：反向传播！沿着计算图自动求导，把梯度存入每个参数的 .grad 属性
  4. 优化器读取梯度，更新权重参数

一句话：自动微分就是深度学习的计算器，自动算出梯度，是训练的核心引擎。

4、损失函数：衡量模型“错得有多离谱”

前向传播输出预测值，需要和真实标签对比。

损失函数 = 误差打分器

  • 预测越准，Loss 越小

  • 预测越偏，Loss 越大

  • 整个训练目标：无限降低损失值

常见：均方误差MSE（回归）、交叉熵Loss（分类，配合Softmax）

一句话：没有损失函数，模型根本不知道自己错没错，没法训练。

常用损失函数以及选型

选择场景 推荐损失函数 原因
普通回归，数据干净 MSE 收敛快、梯度平滑
回归，异常值多 Huber / MAE 抗噪、不被极端值带偏
多分类，类别均衡 Cross-Entropy 标准选择，效果稳定
多标签分类 BCE 每类独立，互不干扰
类别极度不平衡 Focal Loss 聚焦难样本，抑制易样本
图像分割（前景小） Dice Loss / BCE+Dice 直接优化重叠指标
目标检测框回归 Smooth L1 / IoU Loss 尺度不变，稳定
特征学习 / 检索 Triplet / Contrastive 学习嵌入空间距离
模型蒸馏（软标签） KL 散度 对齐教师与学生分布

5、梯度下降算法：真正的“参数更新规则”

有了梯度、有了损失，怎么更新权重？靠梯度下降。

核心逻辑：沿着梯度反方向更新权重，降低损失

重点算法：Adam（整合了Momentum以及RMSProp的优点思想）

Adam的优点：

  • 收敛快：因为有动量，能沿着正确的方向加速。
  • 稳定：因为自适应学习率，不会因为某个参数梯度突然变大而崩掉。
  • 省心：大部分情况下不需要手动调学习率，默认参数（β1=0.9,β2=0.999,η=0.001）就很好用。

公式通俗理解：
新权重 = 旧权重 − 学习率 × 梯度

一句话：梯度下降是让模型不断自我修正、迭代变准的核心算法。

6、学习率：控制模型“改错幅度”

梯度只告诉我们往哪改，学习率告诉我们改多少

学习率过大/过小的缺点：

  • 学习率太大：步子太大，震荡不收敛、容易错过最优解
  • 学习率太小：步子太慢，训练极慢、浪费资源

学习率的控制策略：

  1. 学习率衰减策略，刚开始学习率高，后续逐步减小学习率。作用是刚开始大步走，以便快速到达最优解附近，然后减小学习率，快速找到最优解
  2. 自适应学习率算法（常用），在模型计算时自动跟随结果调整学习率。常见算法包括：Adam，RMSProp

一句话：学习率决定模型训练的快慢与稳定性，是最关键的超参数。

7、激活函数：给网络赋予非线性能力

纯线性层无论叠多深，都等价于单层网络，只能拟合直线。激活函数引入非线性，让网络能拟合复杂规律。

作用：引入非线性，打破纯线性的限制。

常见：Sigmoid、Tanh、ReLU(Leaky ReLU、PPReLU)

  • 放在每一层线性计算之后

  • 没有激活函数，再深的网络等价于单层网络；有了激活函数，网络才能拟合图像、文本这类复杂规律。

  • ReLU：主流激活，解决负数抑制、效率高

  • Softmax：多分类专用，输出概率和为1

一句话：激活函数给神经网络解锁学习复杂模式的能力。没有激活函数，深层神经网络毫无意义。

8、CNN卷积神经网络：专攻图像、空间特征

普通全连接网络看不懂图片（像素有位置关系），专门设计CNN：

  • 核心：卷积核、滑动窗口、提取局部特征

  • 层级特征：浅层抓边缘纹理 → 深层抓轮廓、物体

  • 池化降维、参数共享、减少计算量

一句话：CNN是专门用来处理网格结构数据（图片）的网络，擅长视觉任务。

9、RNN循环神经网络：专攻时序、序列数据

图片是静态的，文本、语音、时间序列是前后有关系的数据。

  • RNN拥有记忆单元，保存上一时刻信息

  • 循环迭代处理每一个时间步数据

  • 适配文本分类、情感分析、时间序列预测

一句话：RNN专门处理前后依赖的序列数据，让模型拥有“记忆”。

10、神经网络：多层张量运算堆叠出来的模型

神经网络 = 一层层**线性变换（张量矩阵乘法）**的叠加。
单层计算：输出 = 权重 @ 输入 + 偏置（纯张量矩阵运算）

  • 如果只有多层线性运算，无论堆多少层，整个网络本质还是一个线性函数，拟合不了复杂曲线。
    👉 这就引出了激活函数！

  • 每一个神经元节点都包含两部分：

    1. 对输入进行线性求和汇总（sum）
    2. 激活函数（一定是非线性的）

一句话：神经网络是一堆带权重的张量运算；但是光有它表达能力有限。

最终完整闭环逻辑

数据转张量 → 网络前向计算（线性+激活）→ 得到预测值 → 损失函数计算误差 → 自动微分求梯度（导数）→ 梯度下降算更新方向 → 学习率控制更新幅度 → 更新权重 → 循环迭代收敛

在此基础上：

  • 图像任务 → 用 CNN 提取空间特征
  • 文本/时序任务 → 用 RNN 提取时序特征
