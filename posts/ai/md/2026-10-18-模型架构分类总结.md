# 当前主流 AI 模型架构分类总结

# 一、模型架构主要分类

当前主流 AI 模型架构主要包括：

-----------------------------------------------------------------------------------------
| 架构            | 英文                 | 代表模型              | 核心特点               |
| --------------- | -------------------- | --------------------- | ---------------------- |
| Encoder-only    | 编码器模型           | BERT、RoBERTa         | 擅长理解文本           |
| Decoder-only    | 解码器模型           | GPT、LLaMA、Qwen      | 擅长生成文本           |
| Encoder-Decoder | 编码器-解码器        | T5、BART、Whisper     | 擅长输入输出转换       |
| Seq2Seq         | Sequence-to-Sequence | T5、Transformer       | 完成序列到序列任务     |
| AutoEncoder     | 自动编码模型         | AE、VAE、BERT思想     | 学习数据表示           |
| Multimodal      | 多模态模型           | GPT-4o、Gemini        | 融合文本、图片、音频等 |
| MoE             | Mixture of Experts   | Mixtral、DeepSeek-MoE | 大参数低计算           |
| SSM             | State Space Model    | Mamba                 | 高效处理长序列         |

------------------------------------------------------------------------

# 二、核心架构说明

## 1. Encoder-only（编码器模型）

特点：

-   只使用 Transformer Encoder。
-   重点是理解输入内容。
-   常采用 Masked Language Model（MLM）训练。

例如：

输入：

    我喜欢吃[MASK]

预测：

    苹果

优势：

-   文本理解强
-   分类、搜索、信息抽取效果好

代表：

-   BERT
-   RoBERTa

适合：

-   文本分类
-   情感分析
-   信息抽取
-   搜索排序

------------------------------------------------------------------------

## 2. Decoder-only（解码器模型）

目前大语言模型最主流架构。

特点：

-   使用 Transformer Decoder。
-   采用自回归（Autoregressive）生成方式。

核心思想：

根据已有 token 预测下一个 token。

例如：

    中国的首都是

预测：

    北京

代表：

-   GPT
-   LLaMA
-   Qwen
-   Claude

优势：

-   文本生成能力强
-   代码能力强
-   推理能力强

------------------------------------------------------------------------

## 3. Encoder-Decoder / Seq2Seq

特点：

由 Encoder 和 Decoder 两部分组成。

流程：

    输入
     ↓
    Encoder理解
     ↓
    Decoder生成
     ↓
    输出

代表：

-   T5
-   BART
-   Transformer

适合：

-   翻译
-   摘要生成
-   文本改写
-   语音识别

------------------------------------------------------------------------

## 4. 自监督学习（Self-supervised Learning）

注意：

自监督不是一种架构，而是一种训练方式。

特点：

模型自己生成训练标签。

例如：

输入：

    今天北京天气

预测：

    很好

目前主流大模型基本都采用：

    自监督预训练
    +
    任务微调

------------------------------------------------------------------------

## 5. 自回归模型（Autoregressive）

特点：

按照顺序逐步生成内容。

公式：

    P(X)=P(x1)P(x2|x1)P(x3|x1,x2)

代表：

-   GPT系列

优势：

-   生成自然
-   适合聊天和代码生成

------------------------------------------------------------------------

## 6. 多模态模型（Multimodal）

特点：

同时理解：

-   文本
-   图片
-   音频
-   视频

例如：

上传图片：

    请解释这张图片

模型可以：

-   识别图片
-   理解内容
-   生成文字回答

代表：

-   GPT-4o
-   Gemini

------------------------------------------------------------------------

## 7. MoE（混合专家模型）

核心思想：

不是所有参数同时工作。

例如：

传统模型：

    100B参数全部激活

MoE：

    100B参数
    选择部分专家计算

优势：

-   参数规模大
-   推理成本低

代表：

-   Mixtral
-   DeepSeek-MoE

------------------------------------------------------------------------

## 8. SSM / Mamba

特点：

使用状态空间模型替代部分 Transformer Attention。

优势：

-   长文本处理效率高
-   计算复杂度低

代表：

-   Mamba

------------------------------------------------------------------------

# 三、架构对比表

----------------------------------------------------------------------------------------------------


| 架构              | 核心能力  | 训练方式     | 优点      | 缺点     | 典型应用         |
| --------------- | ----- | -------- | ------- | ------ | ------------ |
| Encoder-only    | 理解    | MLM自监督   | 理解能力强   | 生成弱    | 分类、搜索        |
| Decoder-only    | 生成    | 自回归      | 生成和推理强  | 计算成本高  | ChatGPT、代码生成 |
| Encoder-Decoder | 转换    | Seq2Seq  | 输入输出能力强 | 结构复杂   | 翻译、摘要        |
| AutoEncoder     | 表示学习  | 重构学习     | 特征提取强   | 生成能力有限 | 降维、表示学习      |
| Multimodal      | 多模态理解 | 多任务自监督   | 信息融合能力强 | 训练复杂   | 图文视频AI       |
| MoE             | 高效扩展  | 自监督+专家路由 | 参数大效率高  | 训练难    | 超大模型         |
| SSM             | 长序列建模 | 序列学习     | 长文本效率高  | 生态较弱   | 长上下文任务       |

------------------------------------------------------------------------

# 四、总结

理解大模型架构可以记住：

| 类型            | 关键词   | 类比             |
| --------------- | -------- | ---------------- |
| Encoder-only    | 理解     | 阅读专家         |
| Decoder-only    | 生成     | 写作专家         |
| Encoder-Decoder | 转换     | 翻译专家         |
| 自监督          | 学习方式 | 自己产生答案     |
| 自回归          | 生成方式 | 一个字一个字生成 |
| MoE             | 扩展方式 | 多专家协作       |
| Multimodal      | 输入能力 | 理解多种信息     |

当前主流大语言模型路线：

    Transformer
        |
        |
    Decoder-only
        |
        |
    自监督预训练
        |
        |
    指令微调
        |
        |
    RLHF/对齐
        |
        |
    MoE + 多模态 + Agent

目前 GPT、LLaMA、Qwen、DeepSeek 等主流大模型基本采用：

**Decoder-only Transformer + 自监督预训练 + 指令微调 + 对齐优化 +（部分）MoE结构**

这是当前大语言模型发展的主流方向。
