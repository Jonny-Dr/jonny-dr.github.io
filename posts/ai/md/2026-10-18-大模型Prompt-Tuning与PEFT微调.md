# 大模型 Prompt-Tuning 与 PEFT 参数高效微调

> 本文覆盖「Prompt-Tuning 方法」「PEFT 分类」「Prefix-Tuning」「LoRA」等核心内容。

---

## 一、超大规模参数模型的 Prompt-Tuning 方法

### 1. 为什么 Prompt-Tuning 对大模型更有效？

近两年来，随着 Prompt-Tuning 技术的发展，对于超过 **10 亿参数量** 的模型来说，Prompt-Tuning 所带来的增益已可媲美甚至超过传统的 Fine-tuning。例如 **GPT-3**，只需要设计合适的模板或指令，即可实现**免参数训练的零样本学习**。

**根本原因：**

- 模型参数量足够大；
- 训练过程中使用了足够多的语料；
- 设计的预训练任务足够有效。

**具体展开（"为什么对大模型更加有效"）：**

1. **参数足够大**：模型本身已经从"小学生"变成了"教授"，内部已经储存了海量的知识；
2. **训练语料足够多**：它"阅读"的文本极其丰富，见过各种各样的任务和表达方式；
3. **预训练任务足够有效**：最初的训练方式（如预测下一个词）让它具备了强大的通用推理能力。

> **意味着什么？**
> 不像以前那样，通过更新数百万或数十亿的参数"教"它一个新任务；只需要通过精心设计的"提示"，去"唤醒"和"引导"模型内部已有的能力，让它直接以**零样本**或**少样本**方式为该任务提供高质量的答案。这就是一种**"零参数训练的高效方式"**。

---

### 2. 面向超大规模模型的 Prompt-Tuning 三大方法

#### ① 上下文学习（In-Context Learning）

- **做法**：直接挑选少量的样本作为该任务的提示（示例）。
- **示例：**
  - 苹果是水果
  - 桌子是家具
  - 汽车是什么？
- **本质**：不提供具体示例即可，直接给模型一个清晰、明确的"任务指令"（如"请将以下英文翻译成中文"），依赖模型对自然语言指令的理解能力；要求指令必须清晰、没有歧义，考验使用者的提问能力。

#### ② 指令学习（Instruction-Tuning）

- **做法**：构建任务指令集，促使模型根据任务指令做出反馈。

#### ③ 思维链（Chain-of-Thought）

- **做法**：给予或激发模型具有推理和解释的信息，通过链式的模式指导模型生成合理的结果。

## 二、Instruction-Tuning

**核心思想**：Instruction-Tuning 和 Prompt-Tuning 的核心一样，都是去**发掘语言模型本身具备的知识**。

### 1. 以"电影评论二分类"为例

在对电影评论进行二分类时：

- **最简单的提示模板（Prompt）**：`{评论原文}. It was [mask].`
- **进阶模板（加入 Instruction）**：`The movie review is: {评论原文}. It was [mask].`

根据 mask 位置的输出结果，通过 **Verbalizer** 映射到具体的标签上。这一类**具备任务特性的模板**可以称之为"指令（Instruction）"。

---

### 2. 电影评论情感分类的三种方式

#### 基础方式：简单的提示模板
- **模板**：`{评论原文}. it was [mask]`
- **示例**：`the movie has a great storyline and amazing acting, it was [mask]`
- **问题**：这个模板太模糊。[mask] 位置模型可以预测任何词，比如 great（正面）、boring（负面）、甚至是 long（中性），任务目标不清晰，模型容易"跑偏"。

#### 进阶方法：加入明确的指令
- **模板**：`the movie review is: {评论原文}. it was [mask]`
- **示例**：`the movie review is: the movie has a great storyline and amazing acting, it was [mask]`
- **关键提升：**
  - **任务界定**：开头的 `the movie review is:` 就是一句明确的指令，直接告诉模型：你现在处理的是一个电影评论文本，相当于给模型划定了参考范围；
  - **聚焦知识**：该指令能瞬间激活模型在预训练阶段学习到的所有与"电影评论"相关的知识（如形容电影的常用词汇、情感倾向等），让它明白接下来的填空应该围绕影评的优劣展开。

#### 标签映射（Verbalizer）
无论使用哪种模板，得到 [mask] 位置的预测词（例如 great 或 terrible）后，还需要一个 **Verbalizer（标签映射器）**，将该词语映射到最终的分类标签上。

### 3. 推理类任务的模板设计（太空停留时长案例）

**前提（Premise）**：俄罗斯宇航员瓦列里·波利亚科夫在 1994-1995 年间创造了连续在太空停留时间最长的纪录，长达 **438 天**。

**假设（Hypothesis）**：俄罗斯人保持着在太空停留时间最长的纪录。

**目标（Target）**：Entailment / Not entailment　选项：yes / no

为这一任务设计了多种模板，例如：

| 模板 | 内容 |
|---|---|
| **Template 1** | `<premise>` Based on the paragraph above, can we conclude that `<hypothesis>`? `<options>` |
| **Template 2** | Can we infer the following? `<hypothesis>` `<options>`　→　我们能否推断出以下结论？`<假设>` `<选项>` |
| **Template 3** | Read the following and determine if the hypothesis can be inferred from the premise: Premise: `<premise>` Hypothesis: `<hypothesis>` `<options>`　→　阅读以下内容并判断假设是否能从前提中推断出来：前提：`<前提>` 假设：`<假设>` `<选项>` |
| **Template 4...** | （以此类推） |

> **实践建议**：为每个任务设计 **10 个指令模板**，测试时看**平均表现**。

## 三、PEFT（参数高效微调）分类

### 方法一：Prefix / Prompt-Tuning
- **做法**：在模型的**输入或隐层**添加 k 个额外可训练的**前缀伪 tokens**，只训练这些前缀参数。

### 方法二：Adapter-Tuning
- **做法**：将较小的神经网络层或模块插入预训练模型的**每一层**，这些新插入的神经模块称为 **adapter（适配器）**。下游任务微调时**只训练这些适配器参数**。

### 方法三：LoRA（低秩自适应）
- **做法**：通过学习**小参数的低秩矩阵**来近似模型权重矩阵 W 的参数更新，训练时**只优化低秩矩阵参数**。

---

## 四、Prefix-Tuning 详解

### 一：前缀/提示调优（Prefix/Prompt-Tuning）

- **核心思想**：不修改模型内部结构，而是在模型的"输入端"或"思考过程中"动脑筋，相当于给模型一张详细的"任务指令"。
- **技术实现**：在原始输入序列之前，添加一小段**可以训练、连续的"前缀"**（一组特定的向量参数）；微调时只优化这些前缀参数，**模型自身的全部参数保持冻结**。
- **工作方式：**
  1. **输入阶段**：在输入文本的嵌入层前拼接可训练前缀；
  2. **隐层阶段**：在模型每一层的激活（隐层状态）前添加可训练前缀。
- **特点**：非常轻量，几乎不增加模型的计算量，但需要精心设计或学习这些前缀。
- **比喻**：就像给汽车的通用 GPS（模型）输入目的地（原始输入）前，给一段特定的路线指示码（前缀参数），让它能更好地导航到目的地。

### 二：适配器调优（Adapter-Tuning）

- **核心思想**：在预训练模型的每个 Transformer 层内部，嵌入一个微型的、可调节的"适配器"。
- **技术实现**：在预训练的每个 Transformer 层插入一个额外的小型神经网络模块（Adapter）；下游任务微调时，**冻结原始模型所有参数，只训练新插入的 Adapter**。
- **特点**：Adapter 虽然增加了模型的计算量，但与模型结合更紧密，通常能取得优秀的性能，且模块化设计便于扩展和迁移。
- **比喻**：像在汽车的每个气缸旁增加一个可调节的"涡轮增压适配器"，通过微调这些小型适配器改变发动机输出、适应不同赛道，而无需改动发动机本身。

### 三：LoRA（低秩自适应）

- **核心思想**：模型在适应新任务时，其权重的改变具有"简单"的内在结构，可以用**低维矩阵来近似表示**。

## 五、Prefix-Tuning 数学表达与训练细节

- **数学表达**：Prefix-Tuning 在输入前添加前缀，即 `z = [Prefix, x, y]`，`Pidx` 为前缀序列的索引，`|Pidx|` 为前缀的长度。前缀索引对应着由 θ 参数化的向量矩阵 **Pθ**，维度为 `|Pidx| × dim(hi)`。

- **训练细节（重要）**：直接更新 Prefix 的参数会导致**训练不稳定**。作者在 Prefix 层前面加了 **MLP 结构**（相当于将 Prefix 分解为更小维度的 Input 与 MLP 的组合后输出的结果）；**训练完成后，只保留 Prefix 的参数**。

### 自回归模型（GPT）
- **工作模式**：单向生成。只能从左到右"阅读"，任务是根据已有的上文预测下一个最可能的词，如此循环，直至生成完整文本。
- **前缀的作用**：前缀和目标语句被放置在同一条连续的序列中；前缀像是给读者提供故事背景或核心关键词；生成过程中，模型会将前缀中的每个关键词都作为上文的一部分来参考。
- **应用场景**：写作、对话生成、代码补全。

### 编码器-解码器模型（BERT、T5、BART）
- **工作模式**：先编码，再解码。
  - **编码阶段**：编码器全面地、双向地阅读并理解整个输入信息（前缀），将其压缩成一个富含语义的"上下文向量"；
  - **解码阶段**：编码和解码分离，解码器拿到"上下文向量"后，开始自回归（一个个词地生成）地生成目标文本。
- **应用场景**：文本摘要、表格转文本。

## 六、Prefix-Tuning 与 P-Tuning、Prompt-Tuning 的对比

### Vs P-Tuning

**1. 嵌入位置和意图**
- **Prefix-Tuning**：将可训练的连续前缀**固定添加到输入序列的最开头**，模仿指令，让模型一开始就接受一个全局的、任务特定的"指令信号"，该信号会贯穿后续的所有计算过程。
- **P-Tuning**：可训练参数（Prompt）的插入位置**相对不固定**，可以是开头、中间或结尾；思路更像是寻找输入序列的间隙并插入提示令牌，激发模型知识。

**2. 作用的深度**
- **Prefix-Tuning**：在 Transformer 的**每一层**都添加了可训练前缀参数；
- **P-Tuning**：通常只是**在最开始的输入嵌入层**加入可训练的 Prompt 参数。

> 补充说明：Prefix-Tuning 将额外的 embedding 加在开头，看起来更像模仿 Instruction 指令；而 P-Tuning 位置不固定。Prefix-Tuning 通过**每层添加可训练参数 + MLP 初始化**；P-Tuning 只在输入时加入 embedding，通过 **LSTM + MLP 初始化**。

### Vs Prompt-Tuning

**Prompt Tuning 可以看作是 Prefix-Tuning 的简化版。**

**1. 参数作用范围**
- **Prefix-Tuning**：在每一层都添加前缀参数，参数量相对较多，**效果强，但计算成本高**；
- **Prompt Tuning**：只在输入嵌入层（第一层）添加可训练的 Prompt Token，继承了"在开头加连续提示"的思想，**放弃了每层都加的复杂设计**。

**2. 训练难度**
- **Prefix-Tuning**：因为参数深、复杂，需要 **MLP 辅助初始化**以保证训练稳定；
- **Prompt Tuning**：结构简单，**不需要 MLP 等辅助结构**，直接训练 Prompt Token，降低了实现难度。

## 七、LoRA 技术三步拆解

> 配图示意：`h` 输入 → 预训练权重 `W ∈ R^{d×d}`（冻结），旁支矩阵 `A = 𝒩(0, σ²)`（随机初始化）、`B = 0`（零初始化），中间为秩 `r`。

**LoRA 概述**：冻结预训练模型的权重，并在每个 Transformer 块中注入可训练层（称为**秩分解矩阵**），即在模型的 Linear 层旁边增加一个"旁支"A 和 B。其中：

- **A** 将数据从 d 维降到 r 维（r 是 LoRA 的秩，是一个重要超参数）；
- **B** 将数据从 r 维升到 d 维，**B 部分参数初始为 0**；
- 训练结束后，需要将 A+B 部分的参数与原始大模型参数**合并**在一起使用。

### 第一步：冻结主体，注入旁支
- **核心操作**：冻结预训练大模型的权重参数（图中蓝色），让它们在整个微调过程中保持不动；
- **关键创新**：在模型原有的线性层旁边，并行增加一个"旁支"，由两个小矩阵 A 和 B 组成。

### 第二步："降维-升维"的结构
- **矩阵 A（下投影）**
  - 作用：将输入数据由高维度 d 降维到很低的维度 r（r 即 LoRA 的秩，是一个超参数，通常远小于 d，例如 d=1024、r=8）；
  - 初始化：通常采用**高斯随机初始化**。
- **矩阵 B（上投影）**
  - 作用：将经过 A 变换后的低维特征（维度 r）再升维回原始维度 d；
  - 初始化：B 的初始参数**设置为 0**——保证训练刚开始时整个旁支的输出为 0，模型行为与原始预训练模型完全一致，不会因新增结构而产生不稳定的初始输出，确保训练的平稳起点。

### 第三步：训练与合并，实现零延迟
- **训练阶段**：只训练旁支的两个小矩阵 A 和 B 的参数。由于 r 很小，A、B 的参数量极少，**训练成本非常低**；
- **推理阶段**：
  - 操作：训练完成后，将旁支学到的"知识"与原始模型合并——将低秩更新矩阵 **B×A 直接加到原始权重 W** 上；
  - 优势：合并后，新模型 W 在结构上与原始模型没有任何区别，不会增加额外计算层，可以**与原模型完全相同的速度进行推理，实现零推理延迟**。

## 八、总结

| 方法 | 可训练参数 | 修改位置 | 计算成本 | 主要特点 |
|---|---|---|---|---|
| **Prompt-Tuning** | 第一层输入嵌入的 Prompt Token | 输入嵌入层 | 低 | 简化版 Prefix-Tuning，无需辅助结构，实现简单 |
| **P-Tuning** | 输入嵌入处的 Prompt（位置不固定） | 输入嵌入层 | 低 | LSTM+MLP 初始化，插入位置灵活 |
| **Prefix-Tuning** | 每层前缀参数 | 每一层 | 中高 | 效果强，需 MLP 辅助初始化保证稳定 |
| **Adapter-Tuning** | 每层插入的 Adapter | 每层内部 | 中 | 与模型结合紧密，模块化、可迁移 |
| **LoRA** | 旁支低秩矩阵 A、B | Linear 层旁支 | 低 | 冻结主体只训旁支，训练后合并零延迟 |

> **核心思想一句话**：与其费尽心力地"教"大模型新知识，不如通过提示/前缀/适配器/低秩旁支等轻量手段，去"唤醒"和"引导"模型内部早已具备的能力——这就是参数高效微调（PEFT）的精髓。
