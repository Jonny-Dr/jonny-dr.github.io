基于RNN的歌词预测Demo完整流程

1、构建词表

类似于字典，供后续模型使用

获取文本数据

分词，并进行去重

构建词表

主要是获取文本去重后的数量、文本去重后的数据集以及对应的索引、使用索引构建的数据集对象（将数组中的数据替换为词表中的索引）

主要输出：

  • 去重以后的词列表
  • 去重以后的词和索引的字典
  • 将所有数据以索引替换并且以空格索引分隔后的完整内容
  • 去重后词表的个数

2、构建数据集对象

为什么需要自己实现Dataset？
因为普通的Dataset不支持数据往前每次移动1位的过程

自己实现Dataset，需要实现如下3个方法：

  • __init__：初始化参数
  • __getitem__：获取x_train、y_train，y_train相对x_train是将位置往后整体移动了1位
  • __len__：获取分段的个数

主要目的：

  • init函数，通过传入的数据以及批次长度获取总的批次数
  • getitem函数，通过当前索引以及批次大小和批次数，防止索引越界，并获取对应索引位置的数据
  • len函数，返回需要的总批次数量

3、网络模型构建

使用RNN神经网络，用于实现歌词预测，主要包含三层

  1. 词嵌入层：用于将语料转换为词向量
  2. 循环网络层：提取句子语义
  3. 全连接层：输出对词典中每个词的预测概率

4、模型训练

4.1 训练超参数配置

在训练开始前，预先定义训练所需超参数：学习率、迭代轮数(epoch)、批次大小、隐藏层维度、嵌入向量维度、设备选择（CPU/GPU）。

同时定义损失函数与优化器：

  • 损失函数：选用交叉熵损失CrossEntropyLoss，适合多分类任务，用来对比预测词概率分布与真实标签之间的差距。
  • 优化器：选择Adam优化器，自适应调整学习率，加快模型收敛。

4.2 加载数据集与迭代器

将前面自定义的Dataset数据集对象传入DataLoader，开启数据分批加载，设置是否打乱数据(shuffle)。歌词生成属于时序任务，一般不打乱样本顺序，保证文本上下文时序关系。

4.3 训练循环流程

  1. 将RNN模型切换至训练模式 model.train()，开启Dropout等训练专属逻辑；
  2. 遍历每一轮epoch；
    • 遍历DataLoader取出每一批训练样本：输入序列x_train、目标序列y_train；
    • 梯度清零：optimizer.zero_grad()，防止梯度累积；
    • 前向传播：将x_train送入RNN网络，得到每个位置所有词汇的预测输出；
    • 计算损失值：对比预测输出和真实标签y_train；
    • 反向传播 loss.backward()，自动计算各参数梯度；
    • 梯度裁剪（时序RNN可选）：解决RNN训练过程中容易出现的梯度爆炸问题；
    • 优化器执行参数更新 optimizer.step()；
  3. 每个训练轮次结束后打印当前epoch编号、本轮损失值，监控模型收敛情况；
  4. 训练全部结束之后，保存训练完成的模型权重文件（.pth），方便后续测试、推理使用。

训练核心逻辑说明：模型学习输入歌词序列，预测下一个位置出现的歌词，不断通过损失反向更新网络权重，逐步记住歌词上下文之间的词语依赖关系。

5、模型测试

5.1 测试准备工作

  1. 加载训练保存好的模型权重；
  2. 将模型切换到评估模式 model.eval()；关闭梯度计算，提升推理速度，禁用训练层；
  3. 关闭自动求导 torch.no_grad()，测试阶段不需要反向传播。

5.2 预测推理方案

歌词生成

采用自回归预测方式：给定一段起始种子文本（开头几句歌词），循环生成后续歌词：

  1. 将种子文本分词，转换成词表对应的索引序列，作为初始输入；
  2. 将输入序列送入训练好的RNN模型，预测得到下一个词的概率分布；
  3. 选取概率最高的词汇索引（或采样策略随机选词，提升歌词多样性）；
  4. 将预测出来的新词索引追加到输入序列末尾，作为下一轮预测的输入；
  5. 循环迭代，直到生成歌词达到预设文本长度，停止生成。

5.3 结果输出

  1. 将生成得到的索引序列反向映射回原始文字，还原出生成的完整歌词文本；
  2. 输出最终生成歌词结果。

5.4 模型性能评估

本次歌词生成任务属于自然语言生成任务，无法使用单一准确率指标评判模型效果，采用客观量化指标+人工主观评价相结合的方案完成模型评估。

  1. 困惑度(PPL)：在独立测试集上计算模型的困惑度，衡量模型预测下一个词语的不确定性，困惑度越低代表模型预测能力越强。
  2. 损失对比分析：对比训练集损失和测试集损失曲线，判断模型是否出现过拟合或欠拟合现象。
  3. 生成文本多样性指标：通过Distinct‑1、Distinct‑2指标评估生成歌词词汇的丰富程度；统计文本重复率，检测模型是否存在词语循环重复退化问题。
  4. 人工评估：从文本连贯性、语句流畅度、歌词风格、原创性、押韵效果5个维度，对生成歌词样本进行人工打分，综合判断歌词生成质量。

import os
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader

def build_vocab(file_path):
    with open(file_path, "r", encoding="utf-8") as f:
        text_data = f.read()
    text_data = text_data.replace("\n", "").replace(" ", "")
    words = list(text_data)
    unique_words = list(set(words))
    word2idx = {word: i for i, word in enumerate(unique_words)}
    idx2word = {i: word for i, word in enumerate(unique_words)}
    vocab_size = len(unique_words)
    print(f"词表大小: {vocab_size}, 文本长度: {len(words)}")
    index_data = [word2idx[w] for w in words]
    return index_data, word2idx, idx2word, vocab_size

class LyricDataset(Dataset):
    def __init__(self, data, seq_len):
        self.data = torch.tensor(data, dtype=torch.long)
        self.seq_len = seq_len
        self.total_samples = len(self.data) - seq_len

    def __getitem__(self, index):
        x = self.data[index:index + self.seq_len]
        y = self.data[index + 1:index + self.seq_len + 1]
        return x, y

    def __len__(self):
        return self.total_samples

def create_dataloader(index_data, seq_length, batch_size=8, shuffle=False):
    dataset = LyricDataset(index_data, seq_length)
    dataloader = DataLoader(dataset, batch_size=batch_size, shuffle=shuffle)
    return dataloader

class LyricRNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.RNN(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)

    def forward(self, x, hidden=None):
        out = self.embedding(x)
        out, hidden = self.rnn(out, hidden)
        out = self.fc(out)
        return out, hidden

def create_model(vocab_size, embed_dim, hidden_dim):
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = LyricRNN(vocab_size, embed_dim, hidden_dim).to(device)
    print(model)
    return model, device

def train_model(model, dataloader, vocab_size, device, epoch_num=10, lr=0.001):
    criterion = nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    for epoch in range(epoch_num):
        total_loss = 0.0
        model.train()
        for x, y in dataloader:
            x, y = x.to(device), y.to(device)
            optimizer.zero_grad()
            output, _ = model(x)
            loss = criterion(output.reshape(-1, vocab_size), y.reshape(-1))
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
            optimizer.step()
            total_loss += loss.item()
        avg_loss = total_loss / len(dataloader)
        print(f"Epoch:{epoch + 1}, Loss:{avg_loss:.4f}")
    return model

def save_model(model, save_path):
    os.makedirs(os.path.dirname(save_path), exist_ok=True)
    torch.save(model.state_dict(), save_path)
    print(f"模型已保存至 {save_path}")

def load_model(model, save_path, device):
    state_dict = torch.load(save_path, weights_only=True)
    model.load_state_dict(state_dict)
    model.to(device)
    return model

def generate_lyric(model, start_words, generate_len, word2idx, idx2word, device):
    model.eval()
    words = list(start_words)
    input_idx = [word2idx[w] for w in words]
    input_tensor = torch.tensor([input_idx], dtype=torch.long).to(device)
    hidden = None
    with torch.no_grad():
        for _ in range(generate_len):
            output, hidden = model(input_tensor, hidden)
            predict_idx = torch.argmax(output[:, -1, :], dim=1).item()
            words.append(idx2word[predict_idx])
            input_tensor = torch.tensor([[predict_idx]], dtype=torch.long).to(device)
    return "".join(words)

def main():
    file_path = "data/jaychou_lyrics.txt"
    save_path = "model/lyric_rnn.pth"

    index_data, word2idx, idx2word, vocab_size = build_vocab(file_path)

    seq_length = 10
    dataloader = create_dataloader(index_data, seq_length, batch_size=8, shuffle=False)

    embed_dim = 128
    hidden_dim = 256
    model, device = create_model(vocab_size, embed_dim, hidden_dim)

    model = train_model(model, dataloader, vocab_size, device, epoch_num=10, lr=0.001)

    save_model(model, save_path)

    model = load_model(model, save_path, device)
    result = generate_lyric(model, "梦想", 100, word2idx, idx2word, device)
    print("生成歌词：", result)

if __name__ == "__main__":
    main()
