# 一、循环神经网络

## 1. 什么是RNN
普通全连接、CNN神经网络输入之间相互独立，**没有记忆能力**。
循环神经网络专门用来处理**序列数据**，自带记忆；每一步输出依赖：**当前输入 + 上一时刻的隐藏状态(记忆)**。

> 序列数据举例：文本、语音、时间序列、股票、视频帧

## 2. 网络展开
```
t0: x0 → h0 → y0
t1: x1 + h0 → h1 → y1
t2: x2 + h1 → h2 → y2
```

## 3. RNN 三种任务模式
1. **一对一**：普通输入输出，如图像分类
2. **多对一**：多个序列输入，单个输出 → 情感分类（一段话输出正面/负面）
3. **多对多**：输入序列，输出序列 → 机器翻译、语音转文字

## 4. 原生RNN致命缺陷
**长距离依赖问题 + 梯度消失/梯度爆炸**
句子很长时，很早之前的信息传到后面几乎丢失，记不住久远内容。

## 5. RNN改进版本
1. **LSTM（长短期记忆网络）**
    新增遗忘门、输入门、输出门、细胞状态Cell‑State，大幅缓解长距离记忆丢失，工业最常用。
2. **GRU（门控循环单元）**
    LSTM简化版，只有更新门、重置门；参数更少，训练速度更快。

> 现状：NLP主流已经被Transformer替代；时序预测、语音场景仍大量使用LSTM/GRU。

## 6. 通俗例子
句子：**我昨天去公园，那里风景很美**
原始RNN读到"很美"时，很难记住开头的"公园"；LSTM可以长久保存这条信息。

# 二、RNN PyTorch实战代码
> RNN时序预测代码样例

任务：使用单层RNN学习正弦曲线，用一段序列预测下一个数值

```python
import torch
import torch.nn as nn
import numpy as np

# ---------------------- 1. 构造数据集 ----------------------
# 正弦曲线时序数据
time_steps = np.linspace(0, 20, 200)
data = np.sin(time_steps)
data = data.reshape(-1, 1)

# 超参数
seq_len = 10      # 输入序列长度
batch_size = 1
input_size = 1    # 每一时刻特征维度
hidden_size = 16  # RNN隐藏层神经元
output_size = 1

# 构造样本：前seq_len个点预测下1个点
def create_seq_data(data, seq_len):
    xs, ys = [], []
    for i in range(len(data)-seq_len):
        x = data[i:i+seq_len]
        y = data[i+seq_len]
        xs.append(x)
        ys.append(y)
    return np.array(xs), np.array(ys)

X, Y = create_seq_data(data, seq_len)

# 转为tensor, shape: [样本数, seq_len, input_size]
X = torch.from_numpy(X).float()
Y = torch.from_numpy(Y).float()

# ---------------------- 2. 定义RNN模型 ----------------------
class SimpleRNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.hidden_size = hidden_size
        # RNN层
        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=1,
            batch_first=True   # 输入格式 (batch, seq_len, feature)
        )
        # 全连接输出层
        self.linear = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        # 初始隐藏状态 h0
        h0 = torch.zeros(1, x.size(0), self.hidden_size)
        # out: (batch, seq_len, hidden_size)
        out, _ = self.rnn(x, h0)
        # 取序列最后一步的隐藏状态做预测
        out = self.linear(out[:, -1, :])
        return out

model = SimpleRNN(input_size, hidden_size, output_size)

# ---------------------- 3. 损失函数&优化器 ----------------------
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# ---------------------- 4. 训练 ----------------------
epochs = 100
for epoch in range(epochs):
    optimizer.zero_grad()
    pred = model(X)
    loss = criterion(pred, Y)
    loss.backward()
    optimizer.step()

    if (epoch+1) % 10 == 0:
        print(f"Epoch:{epoch+1:3d}, Loss:{loss.item():.4f}")

# ---------------------- 5. 测试预测 ----------------------
test_seq = X[0:1]   # 取第一条序列
y_pred = model(test_seq)
print("\n输入序列最后一段预测值：", y_pred.item())
```

> 切换LSTM只需修改两处

```python
# 1. 网络定义处
self.rnn = nn.LSTM(input_size, hidden_size, num_layers=1, batch_first=True)

# 2. 前向传播初始化
h0 = torch.zeros(1, x.size(0), self.hidden_size)
c0 = torch.zeros(1, x.size(0), self.hidden_size)
out, _ = self.rnn(x, (h0, c0))
```

# 三、CNN卷积神经网络 VS RNN循环神经网络对比

## 核心一句话区分
- **CNN（卷积神经网络）**：提取**空间局部特征**；输入之间无先后时序关系
- **RNN/LSTM**：提取**时序上下文特征**；数据有先后顺序，依靠隐藏状态保存记忆

## 详细对比表
| 对比维度 | CNN卷积神经网络 | RNN循环神经网络(LSTM/GRU) |
|---|---|---|
| 适用数据 | 空间数据：图片、图像、矩阵 | 序列数据：文本、语音、时间序列、视频帧 |
| 核心思想 | 滑动卷积核提取局部空间特征 | 循环传递隐藏状态，保存历史记忆 |
| 数据依赖 | 样本之间**相互独立**，无先后顺序 | 当前结果依赖**前面历史时刻数据** |
| 权重共享 | 卷积核在**空间维度**共享权重 | 循环单元在**时间维度**共享权重 |
| 长距离问题 | 感受野有限，远距离像素难关联；无梯度消失问题 | 原始RNN存在**梯度消失，记不住久远信息** |
| 运算方式 | 并行计算，GPU加速很快 | 时序串行，t1算完才能算t2，很难并行 |
| 典型任务 | 图像分类、目标检测、图像分割 | 文本情感分类、机器翻译、时序预测 |

## 通俗案例
1. CNN：识别猫咪图片，卷积依次识别边缘→线条→耳朵→猫咪，不需要记住之前看过哪个像素。
2. RNN：句子`我喝完水，然后去打球`；读到打球时，模型需要记住前面主语"我"是谁。

## 混合方案 CNN‑RNN
- 视频识别：CNN提取每一帧图像特征 → RNN学习帧与帧之间时序关系
- 文本：CNN提取局部词组特征 → RNN学习长上下文

# 四、Transformer（注意力机制）
> 论文：Attention Is All You Need(2017 Google)；GPT、LLaMA、BERT底层骨架

## 1. 为什么诞生Transformer
- RNN/LSTM：串行计算，训练慢；长序列容易丢失久远信息
- CNN：只能看到局部窗口；远距离依赖需要堆叠很多层网络

✅ Transformer两大优势：
1. **所有文字Token同时并行计算，训练速度飞快**
2. **自注意力Self‑Attention**：任意两个单词直接建立联系，一步捕获长距离依赖

## 2. 大白话理解自注意力
句子：`猫 追 老鼠，它跑得很快`
- RNN：一个字一个字顺序读；读到"它"，费力回忆前面内容，长句子容易忘
- Transformer：一眼扫完整句话；读到"它"瞬间直接找到"老鼠"，知道指代对象

> Transformer灵魂：**让每个字都可以和句子中任何一个字直接计算关系强弱**

## 3. Q、K、V通俗解释
- **Q(Query 查询)：我要去找谁？** "它"想要寻找自己指代的对象
- **K(Key 键/名片)：每个单词亮出自己的身份名片**
- **V(Value 值)：每个单词携带的真实内容信息**

流程：
1. "它"拿着Q，挨个对比句子所有单词的K，计算匹配度
2. 匹配度最高的是"老鼠"，给老鼠打很高的注意力权重
3. 把老鼠携带的信息V拿过来给自己
4. "它"就知道自己指代老鼠

## 4. 缩放点积注意力公式
$$
Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$
步骤：
1. $Q\cdot K^T$：计算两两单词相关性得分
2. 除以$\sqrt{d_k}$缩放，防止向量维度太大数值爆炸
3. softmax转为0‑1权重，权重之和=1
4. 权重 × V，加权求和得到融合上下文的向量

## 5. 多头注意力 Multi‑Head‑Attention
把QKV切分成多份，并行跑多次注意力。
好比8个人从8个不同角度读一句话：
- 头1：代词指代关系
- 头2：主谓关系
- 头3：时序关系
最后拼接所有结果，信息更全面。

## 6. 位置编码 Positional Encoding
Transformer一次性读取全部文字，**天生分不清词语顺序**。
`我打你` 和 `你打我` 文字相同，顺序不同语义相反。
解决方案：手动给每个token打上位置序号，词向量+位置向量 =最终输入向量。

## 7. Encoder 编码器（BERT‑双向阅读理解）
单层Encoder内部结构：
> 多头自注意力 → Add&Norm(残差+层归一化) → FFN前馈网络 → Add&Norm

- 双向注意力：每个单词既可以向左看，又可以向右看全部文字
- 使用场景：文本分类、情感分析、语义向量提取

## 8. Decoder解码器（GPT‑单向生成）
单层Decoder内部结构：
> 掩码多头自注意力 → Add&Norm → 交叉注意力(翻译专用) → Add&Norm → FFN前馈网络

- **掩码Mask**：生成文字的时候，遮住未来还没有生成的词，禁止偷看后面内容
- GPT属于**纯Decoder架构**，自左向右一个字一个字生成文本
- 交叉注意力：仅Encoder‑Decoder翻译架构使用，GPT无此模块

## 9. 三大Transformer架构路线
| 架构类型 | 代表模型 | 结构 | 用途 |
|---|---|---|---|
| Encoder‑Only | BERT | 只用编码器 | 理解任务：分类、情感分析、语义向量 |
| Decoder‑Only | GPT‑3.5/4、LLaMA、通义千问 | 纯解码器+掩码注意力 | 生成任务：对话、写文章、代码续写 |
| Encoder+Decoder | T5、Bart | 编码器+解码器 | 序列转换任务：机器翻译、文本摘要 |

## 10. Transformer VS RNN总结对比
| RNN/LSTM | Transformer |
|---|---|
| 串行计算 t1→t2→t3，训练慢 | 全部token并行计算，GPU训练飞快 |
| 信息一步步传递，长距离信息容易丢失 | 自注意力直接连通任意两个词，长距离依赖友好 |
| 自带时序属性，无需位置编码 | 无顺序概念，必须手动添加位置编码 |
| 上下文单向流动 | Encoder双向自注意力，可以同时看左右所有单词 |

# 五、Transformer极简示例

```python
import torch
import torch.nn as nn

# 超参数
vocab_size = 1000   # 词表大小
d_model = 128       # 词向量维度
nhead = 2           # 注意力头数
num_layers = 2      # decoder层数
seq_len = 10

# 1. 词嵌入层：数字token → 向量
embedding = nn.Embedding(vocab_size, d_model)

# 2. Transformer解码器层
decoder_layer = nn.TransformerDecoderLayer(d_model, nhead, batch_first=True)
transformer_decoder = nn.TransformerDecoder(decoder_layer, num_layers=num_layers)

# 3. 输出层：向量转回单词概率
linear = nn.Linear(d_model, vocab_size)

# 模拟输入：一批句子，每个句子10个词(用数字代表单词)
x = torch.randint(0, vocab_size, (2, seq_len))  # batch=2, 序列长10

# 生成掩码：遮住未来位置，GPT必须要有
mask = nn.Transformer.generate_square_subsequent_mask(seq_len)

# 前向传播
x_emb = embedding(x)
# 纯decoder的时候memory可以传全0占位
memory = torch.zeros_like(x_emb)
out = transformer_decoder(tgt=x_emb, memory=memory, tgt_mask=mask)
logits = linear(out)

print("输出shape:", logits.shape)
# [batch, seq_len, vocab_size]，每个位置预测下一个词
```

# 六、知识点速查卡片
1. **RNN**：时序串行，靠隐藏状态传递记忆；长序列梯度消失。升级版LSTM/GRU
2. **CNN**：空间并行；卷积核提取局部图像特征，无记忆
3. **Self‑Attention自注意力**：token之间直接计算相关性，长距离依赖一步到位，并行训练
4. **QKV**：查询、键、值；注意力机制三要素
5. **Encoder(BERT)**：双向注意力，理解文本
6. **Decoder(GPT)**：掩码单向注意力，自回归生成文本
7. **位置编码**：给Transformer增加词语先后顺序信息
